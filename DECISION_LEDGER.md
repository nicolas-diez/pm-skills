# DECISION LEDGER (template)

> The engine's most defensible asset over time: a proprietary dataset of decisions + their real outcomes. Methodology is copyable; this ledger is not. Each run appends a row; the `outcome` is filled later, when it's known — that's the valuable part.
>
> **Keep real ledger data private.** This is a blank template. Populate it in your own private workspace, not in a public repo.

## How to fill
Each initiative that passes through the engine appends a row at close. Complete `outcome` when the result is known.

| Date | Company/client | Initiative | Main deal-breaker flagged | Engine confidence | Threshold / kill gate | Decision made | Real outcome (fill later) | Engine right? |

| | | | | | | | → fill | |

## Ledger metrics (the objective evaluator — the moat)
- **Hit rate:** of the decisions where the engine said "kill/change," how many turned out correct?
- **Accumulated savings:** sum of "avoided spending $X" (what actually gets bought).
- **Decision-change rate:** % of initiatives whose roadmap changed materially because of the engine (north-star).

## Rule
Never invent outcomes. `outcome` is filled only with real data; until then `→ fill`. An honest ledger is the asset; an inflated one is worthless.
